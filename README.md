💅 NaildBy_Steph™ Unified OS
Welcome to the official repository for NaildBy_Steph™, a full-stack salon SaaS platform built to empower artists, owners, and creatives of all kinds. This is the final unified build — sequenced, staged, and ready for deployment to naildbysteph.beauty.
🧩 Project Overview
NaildBy_Steph™ is more than a website — it's a modular universe designed to:
Support female-led businesses with tools for booking, tutorials, voice AI, and client management.
Celebrate creative expression through nail art simulation, adaptive onboarding, and stylistic customization.
Provide a safe, empowering space for users to learn, create, and grow without overwhelm.
Enable scalable deployment with clean architecture, Drizzle ORM, Vite, and modular ZIP sequencing.
🛠️ Tech Stack
Frontend: React + TypeScript (client/)
Backend: Node + Drizzle ORM (server/, drizzle/)
Shared Logic: Modular utilities (shared/)
Voice AI & Tutorial Layer: AIChatPanel.tsx, useVoiceChat.ts, TUTORIAL.md
Booking & Simulation: TechBooking.tsx, NailSimulator.tsx
Build Tools: Vite, Vitest, PNPM
